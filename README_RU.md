## Быстрый старт за 30 секунд

1. Нажми кнопку **СКАЧАТЬ ДЛЯ LINUX** выше и скачай архив Linux из последнего релиза.
2. Распакуй архив.
3. Открой терминал в распакованной папке и выполни:

```bash
./install.sh
```

4. Зашифруй файл:

```bash
forgecrypt encrypt ./private.txt ./private.txt.fgc
```

ForgeCrypt попросит ввести новый пароль дважды. При вводе символы пароля не отображаются.

## Что умеет ForgeCrypt

| Задача | Команда |
|---|---|
| Зашифровать файл | `forgecrypt encrypt input output.fgc` |
| Расшифровать файл | `forgecrypt decrypt input.fgc output` |
| Проверить зашифрованный файл | `forgecrypt verify input.fgc` |
| Изменить пароль | `forgecrypt rekey input.fgc new-copy.fgc` |
| Посмотреть метаданные формата | `forgecrypt inspect input.fgc` |
| Проверить сведения о сборке | `forgecrypt doctor` |

**Простое правило:** ForgeCrypt никогда не перезаписывает существующий выходной файл. Укажи новое имя.

## Что изменилось в 2.0 GLOBAL

- **Файлы любого размера:** формат v2 обрабатывает данные частями по 1 МиБ и не загружает весь файл в RAM.
- **Аутентификация каждого блока:** каждый блок проверяется отдельно и привязан к своему порядковому номеру.
- **Защита от обрезания:** завершающая аутентифицированная запись позволяет обнаружить неполный файл.
- **Проверка без расшифрованного файла:** `verify` проверяет весь контейнер и не сохраняет plaintext на диск.
- **Смена пароля без временного plaintext-файла:** `rekey` передаёт данные через ограниченный канал в памяти.
- **Безопасное создание результата:** CLI использует временный файл с правами только владельца и публикует результат после успешного завершения операции. Существующие файлы не перезаписываются.
- **Совместимость:** файлы формата v1 из ForgeCrypt 0.1.x и 1.2.x можно расшифровать, проверить, просмотреть и перешифровать. Ограничение старого формата v1 — 16 МиБ.

## Установка

### Вариант A — готовый релиз (рекомендуется)

1. Открой [последний релиз ForgeCrypt](https://github.com/abduforge/forgecrypt/releases/latest).
2. Скачай Linux-архив для своей архитектуры (`x86_64` подходит для большинства Intel/AMD компьютеров).
3. Распакуй архив и открой терминал в папке.
4. Выполни:

```bash
./install.sh
```

Программа будет установлена в `~/.local/bin`. Права root не нужны. Если команда `forgecrypt` не находится, добавь каталог в `PATH`:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.profile
. ~/.profile
```

### Вариант B — сборка из исходников

Требования: Linux, стабильный Rust (1.85 или новее) и Cargo.

```bash
cargo fmt --all -- --check
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo build --release
./install.sh
```

## Команды простым языком

### Шифрование

```bash
forgecrypt encrypt ./document.pdf ./document.pdf.fgc
```

Создаёт новый зашифрованный файл. ForgeCrypt попросит ввести пароль дважды. Используй длинный уникальный пароль и сохрани его в надёжном месте.

### Расшифровка

```bash
forgecrypt decrypt ./document.pdf.fgc ./document-restored.pdf
```

Результат сначала записывается во временный файл с правами `0600`. Запрошенный выходной файл появляется только после проверки всех блоков и завершающей записи. При ошибке аутентификации результат не публикуется.

### Проверка подлинности

```bash
forgecrypt verify ./document.pdf.fgc
```

Проверяет пароль и аутентификацию всего файла. Открытые данные удаляются из временного буфера в памяти; файл с plaintext не создаётся.

### Смена пароля (re-key)

```bash
forgecrypt rekey ./document.pdf.fgc ./document-new-key.pdf.fgc
```

ForgeCrypt попросит текущий пароль, а затем новый пароль дважды. Для файлов v2 данные проверяются и перешифровываются через ограниченный канал в памяти без промежуточного plaintext-файла на диске. Старый файл v1 (до 16 МиБ) открывается в очищаемом буфере памяти и обновляется до v2. Оригинальный зашифрованный файл не меняется.

### Просмотр метаданных

```bash
forgecrypt inspect ./document.pdf.fgc
```

Показывает публичные параметры заголовка. **Команда inspect не проверяет подлинность содержимого.** Для этого используй `verify`.

### Диагностика и помощь

```bash
forgecrypt doctor
forgecrypt --help
forgecrypt --version
```

## Криптографическая основа

ForgeCrypt использует реализации проверенных алгоритмов из специализированных библиотек. Собственные шифры и криптографические протоколы не изобретаются.

| Назначение | Реализация |
|---|---|
| Получение ключа из пароля | Argon2id v1.3 |
| Аутентифицированное шифрование | XChaCha20-Poly1305 |
| Соль и nonce записей | Системный криптографически стойкий генератор через `getrandom` |
| Очистка чувствительных буферов | `zeroize` |
| Скрытый ввод пароля | `rpassword` |

Формат v2 использует новую 16-байтовую соль для каждого файла и новый 24-байтовый nonce для каждой записи. Заголовок, тип записи, номер блока, длина данных, nonce и итоговая длина аутентифицируются как дополнительные данные AEAD. Параметры Argon2id фиксированы и проверяются до запуска KDF: 64 МиБ памяти, 3 итерации, 1 lane.

Подробнее: [docs/FORMAT.md](docs/FORMAT.md), [SECURITY.md](SECURITY.md).

## Совместимость

ForgeCrypt 2.0 записывает новые файлы в **формате v2**. Старые файлы **формата v1** из ForgeCrypt 0.1.x и 1.2.x остаются читаемыми. Формат v1 ограничен 16 МиБ и работает в памяти; v2 предназначен для потоковой обработки крупных файлов. Версия приложения и версия формата контейнера — разные вещи.

## Важные замечания по безопасности

- ForgeCrypt защищает локальные файлы в состоянии покоя. Это **не** VPN, сетевой туннель, P2P-протокол или система идентификации устройств.
- Проект пока не прошёл независимый аудит безопасности. Считай его экспериментальным и не используй как единственную защиту незаменимых или особо ценных данных.
- Слабый или повторно используемый пароль можно подбирать офлайн. Используй длинный уникальный пароль.
- Если пароль потерян, восстановить данные через ForgeCrypt нельзя. Сделай отдельную защищённую резервную копию.
- Имена файлов, размеры и обычные метаданные файловой системы не скрываются.
- Шифрование не защищает данные после расшифровки на заражённом устройстве, а также от вредоносных программ, кейлоггеров, анализа памяти, crash dump или разблокированной сессии.
- CLI сначала записывает результат во временный файл с правами `0600` в каталоге назначения и публикует его только после успешного завершения. Во время `decrypt` этот временный файл содержит открытые данные. При отключении питания или принудительном завершении процесса скрытый `.forgecrypt-*.tmp` может остаться; после прерванной расшифровки считай такой файл открытыми данными.
- Гарантировать безопасное физическое стирание на SSD, CoW-файловых системах, снапшотах и журналируемых носителях нельзя.

## Удаление

```bash
./uninstall.sh
```

Команда удаляет исполняемый файл из `~/.local/bin`, но не удаляет зашифрованные файлы.
